# 🤖 AI Document Assistant

An AI-powered assistant built with **Python**, **Streamlit**, and **Google Gemini** that answers general user questions instantly. No document upload is required.

## ✨ Features
- 💬 Answers general user queries
- 🤖 Powered by Google Gemini AI
- ⚡ Interactive Streamlit interface
- 🔐 Secure API key handling
- 🎯 Fast and accurate AI responses

## 🛠️ Tech Stack
- Python
- Streamlit
- Google Gemini API
- python-dotenv

## 🚀 Run Locally

```bash
git clone https://github.com/your-username/AI-Document-Assistant.git
cd AI-Document-Assistant
pip install -r requirements.txt
streamlit run app.py
```

## 📌 About Project
AI Document Assistant is an AI chatbot application that uses Google Gemini to provide intelligent answers to user questions through a simple and modern Streamlit interface.
